Avery L7171 · 200 × 60 mm · 4 per A4 sheet

KLBD Archive spine labels

All thirty archive files, laid out at true size across eight sheets. Print straight from this page onto label stock — what you see below is exactly where the ink lands. Settings below are for Chrome or Edge on Windows, printing to the Lexmark XC9255.

In Chrome or Edge on the PC
01

Press Ctrl + P and pick the Lexmark XC9255. Open More settings.

02

Tick Background graphics. Without it the navy blocks print blank — this is the one setting people miss.

03

Set Scale to Custom → 100. Chrome’s “Default” scale quietly shrinks the page to fit the printable area, which throws the alignment out by a few millimetres.

04

Set Margins to None, Paper size to A4, and untick Headers and footers. Leave two-sided off.

At the Lexmark
05

Load the label sheets in the multipurpose / bypass tray on the side, face down, not in a paper cassette. Cassettes bend the sheet tightly and can peel labels off inside the machine.

06

On the touchscreen set that tray’s paper type to Labels and size to A4. This slows the feed and adjusts the fuser — running labels as plain paper is what causes jams and adhesive on the rollers.

07

The XC9255 takes A3, so double-check it hasn’t auto-picked an A3 tray. If the machine holds jobs for badge or PIN release, release it there as usual.

Before you commit the label stock
08

Print one test on plain paper and hold it against a label sheet at a window. The dashed guides should sit on the die-cut edges. Feed label sheets one at a time.

09

If it lands a millimetre out, adjust --offset-x / --offset-y in the source file. Sheet 1 carries files 1–4, sheet 2 files 5–8, and so on.
